# 0.20.2 · medidas negativas — cómo se aplica esta rama

Esta rama trae **el cambio completo de 0.20.2 en dos piezas**, porque el conector
de GitHub del chat de draw101 empuja archivos de texto uno por uno y `entrada.js`
y `vista.js` son grandes para reescribirlos enteros por un cambio de 60 líneas:

1. `pruebas/t016_negativos.py` — archivo nuevo, ya está en la rama tal cual.
2. `claude/0.20.2-negativos.patch` — el diff de `ui/entrada.js`, `ui/vista.js`,
   `core/version.py` y `package.json` contra `main` (que es X.0.2). Aplica limpio:

```bash
git checkout claude/0.20.2-negativos
git apply --check claude/0.20.2-negativos.patch && git apply claude/0.20.2-negativos.patch
python verificar.py          # 16 pruebas, 358 comprobaciones
git add -A && git commit -m "0.20.2: medidas negativas (Mike, 12-sep)"
```

Quien lo aplique (Jr.) puede después borrar el `.patch` y este LEEME en el mismo
commit: el código ya queda en los archivos.

## Lo que cambia

- `-300` en ancho/alto de RECTÁNGULO (cajita X/Y o línea de comandos) dibuja a la
  izquierda/abajo aunque el ratón esté del otro lado. Sin signo, como antes.
- La misma regla para la longitud fija de LÍNEA y demás: `-200` = lado contrario
  del cursor.
- Defecto encontrado en el camino: la cajita perdía el signo al rematar con Enter
  (leía la caja, no lo fijado). Arreglado; el campo fijado muestra `-300`.
- `signAndEditExecutable: true` en `package.json`: el `.exe` ya lleva el icono de
  draw101 y no el de Electron (necesita wine32 en Linux; en el corredor Windows
  no necesita nada).
